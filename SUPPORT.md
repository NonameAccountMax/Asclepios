# Support

## Questions and bug reports

Open an issue on GitHub. Please include the input deck (or a reduced version that reproduces the problem), the
command line, and the console output of `asclepios`.

## Professional services

Product-specific simulations and custom validation studies (for example for medical devices) can be arranged.
Open an issue titled `Services: <subject>` with a way to reach you; the maintainer will follow up privately.
Please do not post confidential product information in the issue.
